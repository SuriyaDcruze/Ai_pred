# Historical Memory API (`/memory/*`) — Reference

Complete reference for the Historical Memory REST API shipped in **Sprint 2** (Milestone 5).
Implemented in `app/api/memory.py` (an `APIRouter` mounted in `app/api/main.py`), backed by
the `RetrievalEngine` and `MemoryBuilder` over `data/prediction_history.db`.

**Design contract (ADR 0010):** every endpoint is a thin adapter over the retrieval/builder
domain — no business logic, no direct DB access, no imports from the Prediction/Outcome
engines. Responses are structured JSON. Aggregate statistics are read, never computed, in the
API. Similarity always returns the documented *unavailable* state — never a fabricated score.

Base path: `/memory`. All responses are `application/json`. OpenAPI is generated by FastAPI
(`GET /openapi.json`, Swagger UI at `/docs`).

---

## Data types

### Memory Record (composed, read model)
Returned nested under `record` by `GET /memory/record/{id}`, and in the `records` arrays of
search/timeline. Composed on read from `predictions` + satellites; a missing satellite is
`null`.

| Field | Type | Source |
|---|---|---|
| `prediction_id`, `created_at`, `symbol`, `exchange`, `timeframe`, `source` | string | predictions |
| `direction`, `recommendation` | string | predictions |
| `direction_prob`, `outcome_prob`, `decision_score`, `confidence` | number \| null | predictions |
| `entry`, `stop`, `target1`, `target2` | number \| null | predictions |
| `status` | string | predictions (8-state lifecycle) |
| `trade_result` | string | derived: WIN / LOSS / EXPIRED / CANCELLED / OPEN |
| `resolution_reason`, `resolved_at`, `resolved_price`, `realised_r`, `holding_bars` | mixed \| null | predictions |
| `market_regime`, `market_phase`, `sector`, `session`, `volatility_bucket` | string \| null | predictions |
| `context` | object | predictions |
| `versions` | object | `{prediction_model_version, outcome_model_version, feature_version}` |
| `reasoning` | object \| null | `{rationale, factors, rule_check, confidence}` (satellite) |
| `embedding` | object \| null | `{kind, present, dim, model_name}` — `present:false` until Similarity fills it |
| `aggregate` | object \| null | the record's sector (else overall) rollup summary |
| `metadata` | object | `{built, built_at, builder_version, provenance, source, record_schema_version, …}` |

### Aggregate object
`{dimension, bucket, model_version, n_resolved, wins, losses, win_rate, avg_r, expectancy,
total_r, profit_factor, max_drawdown_r, avg_holding_bars}`. All figures in R-multiples.

## Endpoints

### `GET /memory/record/{prediction_id}`
One fully composed Memory Record.
- `200` → `{ "record": MemoryRecord }`
- `404` → unknown prediction

```bash
curl http://localhost:8000/memory/record/a1b2c3
```

---

### `GET /memory/search`
Filtered, keyset-paginated search. All filters optional, AND-composed.

**Query:** `symbol`, `timeframe`, `sector`, `market_regime`, `outcome` (status or WIN/LOSS
alias), `prediction_model_version`, `outcome_model_version`, `feature_version`,
`confidence_min`/`confidence_max` (0–1), `date_from`/`date_to` (ISO-8601, inclusive),
`limit` (1–500, default 50), `cursor`.

**Responses**
- `200` → `{ "count": int, "next_cursor": string|null, "records": MemoryRecord[] }`
- `422` → invalid filter, bad cursor, or out-of-range limit

Ordering is deterministic `(created_at, prediction_id)` desc; pass `next_cursor` back as
`cursor` for the next page.

```bash
curl 'http://localhost:8000/memory/search?sector=Energy&outcome=WIN&limit=20'
curl 'http://localhost:8000/memory/search?limit=20&cursor=MjAyNi0wMS0wMXwwZjNh'
```

---

### `GET /memory/statistics`
Aggregate rollups (read from `memory_aggregates`, never computed here). Always reports sample
size.

**Query:** `dimension` (`overall|symbol|sector|timeframe|regime|confidence_bucket|outcome`),
`bucket` (optional; requires `dimension`), `model_version` (default `""` = all models).

**Responses**
- `200` → `{ "dimension": string|null, "count": int, "total_resolved": int, "aggregates": Aggregate[] }`
  — `total_resolved` is the non-double-counted sample size (from the combined rollups).
- `422` → unknown dimension, or `bucket` without `dimension`

```bash
curl 'http://localhost:8000/memory/statistics?dimension=sector'
```

---

### `GET /memory/timeline`
Chronological Memory Records (newest first) for a symbol / date window.

**Query:** `symbol`, `from` (ISO), `to` (ISO), `limit` (1–500).
**Response:** `200` → same shape as search (`count`, `next_cursor`, `records`).

```bash
curl 'http://localhost:8000/memory/timeline?symbol=RELIANCE.NS&from=2026-01-01T00:00:00+00:00'
```

---

### `GET /memory/similar/{prediction_id}`
The similarity **contract** — unavailable until the Similarity Engine (Vol 14). No fake
scores (ADR 0011).

**Query:** `k` (1–100, default 5).
- `200` → `{ "available": false, "reason": "Similarity Engine unavailable", "results": [] }`
- `404` → unknown prediction

```bash
curl http://localhost:8000/memory/similar/a1b2c3
```

---

### `GET /memory/context`
A bounded, deterministic GPT grounding bundle.

**Query:** `symbol` (optional), `k` (1–100, default 5).
**Response:** `200` →
```json
{
  "records": [ /* up to k Memory Records, newest first */ ],
  "aggregate": { "dimension": "symbol", "n_resolved": 12, "win_rate": 0.58, "avg_r": 0.31, "profit_factor": 1.6 },
  "sample_size": 12,
  "metadata": { "k": 5, "symbol": "RELIANCE.NS", "returned": 5, "min_meaningful_sample": 50,
                "note": "Sample too small to be conclusive." }
}
```
The bundle always carries `sample_size` + an honest note so the assistant cannot over-claim.

---

### `POST /memory/build/{prediction_id}`
Enrich one completed prediction (idempotent).
- `200` → `{ "prediction_id": string, "status": "built" | "skipped_open" }`
- `404` → unknown prediction

```bash
curl -X POST http://localhost:8000/memory/build/a1b2c3
```

---

### `POST /memory/backfill`
Enrich all completed predictions with no memory yet (idempotent).

**Query:** `limit` (optional, 1–10000).
- `200` → `{ "processed": int, "built": int, "skipped": int, "failed": int }`

```bash
curl -X POST 'http://localhost:8000/memory/backfill?limit=1000'
```

---

### `POST /memory/rebuild-aggregates`
Recompute all derived aggregates from source (idempotent repair path).
- `200` → `{ "rebuilt_rows": int }`

```bash
curl -X POST http://localhost:8000/memory/rebuild-aggregates
```

## Error model
FastAPI's standard shape: `{ "detail": <string | validation-error-list> }`. Stack traces are
never exposed.

| Status | When |
|---|---|
| `404` | unknown `prediction_id` (record / similar / build) |
| `422` | request validation failure — invalid filter, `confidence_min > confidence_max`, unknown `outcome`/`dimension`, malformed cursor, out-of-range `limit` |
| `500` | internal Historical Memory failure (generic message; logged server-side) |
| `503` | retrieval/builder not initialised (misconfiguration) |

## Notes
- **Read-only vs build:** the `GET` endpoints never write; the `POST` endpoints only write
  satellite tables via the Memory Builder — never `predictions`, never a model.
- **Idempotency:** `build`, `backfill`, and `rebuild-aggregates` converge to the same final
  state on repeat.
